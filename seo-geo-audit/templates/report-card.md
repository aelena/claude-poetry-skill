## Methodology

This audit was generated by the `seo-geo-audit` Claude skill. Each check is a piece of semantic reasoning over the source code, not a regex match — meaning findings reflect *content quality*, not just *presence*. Severities map to point deductions from a starting score of 100; see `checks/scoring.md` for details.

The audit is read-only. To apply fixes, run `/audit fix` and confirm each edit.

For accessibility scoring, run `/a11y-audit` (separate skill).
