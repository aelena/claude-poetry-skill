> Typical greenfield Next.js project. The framework gives you a head start on SEO basics, but nothing on GEO. The biggest wins are: add per-page metadata, drop in JSON-LD on the homepage and any content pages, and create an `llms.txt`. None of these are hard — they just haven't been done yet.

## Top fixes (highest leverage first)

### 1. SEO-001 + SEO-004 — Most pages have no `<title>` or `<meta description>`  · *high*

**Where:** `app/layout.tsx:1` (cascades to 9 pages with no override)

**What's wrong:** The root layout sets a generic title ("Next.js App") and no description. Individual pages don't override either. Every page in Google looks identical.

**Fix:**
```tsx
// app/blog/[slug]/page.tsx
export async function generateMetadata({ params }) {
  const post = await getPost(params.slug);
  return {
    title: `${post.title} — Greenfield`,
    description: post.excerpt.slice(0, 155),
    openGraph: { title: post.title, description: post.excerpt, images: [post.cover] }
  };
}
```

### 2. GEO-001 — No `llms.txt` at the site root  · *high*

**Where:** `public/` (file does not exist)

**What's wrong:** LLMs visiting the site have no curated index. They have to crawl everything and guess what matters.

**Fix:** Run the `llms-txt` Claude skill: `/llms-txt`. It will read the README and generate a valid `llms.txt` for you.

### 3. GEO-005 — No JSON-LD anywhere on the site  · *high*

**Where:** entire codebase (0 occurrences)

**What's wrong:** Without JSON-LD, LLMs can't extract typed entities. Your blog posts have no `Article` schema, your homepage has no `Organization` schema, your docs have no `TechArticle` schema.

**Fix:** Start with `Organization` in the root layout and `Article` on blog posts. Two blocks, ~30 lines total.

### 4. GEO-016 — Headings are not self-contained  · *high*

**Where:** `app/blog/[slug]/page.tsx`, plus 5 individual posts

**What's wrong:** Headings like "Background", "The Problem", "Conclusion" mean nothing out of context. LLMs that surface a single section as a citation will produce useless results.

**Fix:** Rewrite headings to be specific. "Background" → "Why we needed a new retry policy". "Conclusion" → "Three lessons from rolling out backoff capping".

### 5. GEO-021 — Code examples are screenshots  · *high*

**Where:** `app/blog/launch.tsx:88`, `app/blog/postmortem.tsx:142`

**What's wrong:** Code is shown as PNG images. Text-only LLMs cannot read it. Embedded into vector search, your "code examples" are noise.

**Fix:** Replace screenshots with real ` ```language ` code blocks.
